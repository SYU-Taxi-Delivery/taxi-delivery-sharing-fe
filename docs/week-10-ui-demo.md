## 발표 전 준비

이 문서가 있는 저장소 루트에서 아래 명령을 실행하고 [로컬 시연 목록](http://127.0.0.1:13266/posts-preview)을 연다. 데모는 예시 사용자 김하늘로 시작하며 백엔드나 계정 설정 없이 동작한다.

```sh
pnpm install --frozen-lockfile
pnpm dev --hostname 127.0.0.1 --port 13266
```

시작 직전에 목록을 한 번 새로고침한다. 출발·주문 시간이 그 시점에 맞춰 다시 정해진다. 시연 중에는 같은 탭에서 카드와 메뉴로 이동해야 방금 참여한 내역을 이어 볼 수 있다. 다시 연습하려면 새로고침한다.

## 빈 화면과 오류 시연

- **검색 결과 없음** — 목록에서 `없는시연검색어`를 검색한다. **조건 초기화**를 키보드로 실행하면 조건을 해제하고 결과 제목으로 포커스를 옮긴다. 참여 가능한 모집이 없을 때는 **마감된 모집도 보기**로 같은 유형의 조회 범위를 넓힌다. [빈 검색 결과](../output/playwright/week10-ui/07-empty-search-mobile.png)
- **목록 조회 실패** — 목록 상단의 **데모 도구 → 상황 → 조회 실패**를 선택하고 도구를 접는다. **다시 불러오기**를 누르면 카드 자리 표시자와 로딩 문구가 나타난다. 실패를 계속 반환하도록 설정한 상태이므로 정상 화면으로 돌아갈 때는 상황을 **정상**으로 바꾼다. [목록 오류](../output/playwright/week10-ui/08-error-desktop.png) · [목록 로딩](../output/playwright/week10-ui/09-loading-mobile.png)
- **내 활동** — 참여 시연을 끝낸 후 **내 참여 · 모집 → 작성한 글**에서 데모 도구의 **조회 실패**를 선택한다. **다시 시도**를 누르면 작성 이력의 로딩 상태를 확인할 수 있다. **빈 이력**으로 바꾸면 모집글 쓰기로 이어진다. 내 활동의 데모 상황을 바꾸면 택시·배달 예시 데이터도 초기화된다. [이력 오류](../output/playwright/week10-ui/10-my-error-mobile.png) · [이력 로딩](../output/playwright/week10-ui/11-my-loading-desktop.png) · [빈 이력](../output/playwright/week10-ui/12-my-empty-mobile.png)

## 점검 결과

| 점검        | 실행 환경과 결과                                                                                                                                                                                                                                                                                               |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 반응형      | Chrome에서 로그인·회원가입·비밀번호 재설정·택시 작성·배달 작성·모집 목록을 320, 390, 768, 1024, 1440px로 확인했다. 30개 조합 모두 페이지 가로 넘침이 없었다. [모바일 로그인](../output/playwright/week10-ui/login-mobile.png) · [데스크톱 배달 작성](../output/playwright/week10-ui/delivery-form-desktop.png) |
| 키보드      | 빈 로그인 제출 후 이메일 입력란으로 복귀, 방향키로 작성 유형 전환, 모바일 필터 열기·닫기와 포커스 복귀, 검색 적용을 확인했다.                                                                                                                                                                                  |
| 시연 리허설 | Chrome 390×844와 1440×900에서 목록 → 택시 참여 → 내 활동 → 배달 참여 → 내 활동, 검색 초기화, 조회 오류·재시도, 빈 작성 이력을 확인했다.                                                                                                                                                                        |
| Vitest      | `pnpm test --maxWorkers=2`에서 51개 파일, 1,184개 테스트 통과. 목록 초기화·재시도 후 포커스, 이력 재조회 전환, 두 시연 모집의 검색과 상세 안내를 검증했다.                                                                                                                                                     |

`pnpm format:check`, `pnpm lint`, `pnpm typecheck`, `pnpm build`도 통과했다.

모바일은 데스크톱 Chrome에서 화면 크기와 터치 입력을 설정해 확인했다. 실제 휴대전화와 Safari, 운영 계정·데이터를 사용한 검증은 이번 결과에 포함하지 않았다.
