## 실제 FE·BE 전체 흐름 — 로컬 H2 demo + 로컬 메일 수신기 → 36/36 통과

BE는 demo 프로필에 `--spring.mail.host=127.0.0.1 --spring.mail.port=2525
--spring.mail.properties.mail.smtp.auth=false --spring.mail.properties.mail.smtp.starttls.enable=false
--server.port=18088`을 주고, 로컬 SMTP 수신기로 실제 인증번호 메일을 받아 사용했다.
FE는 `BACKEND_ORIGIN=http://localhost:18088`. Chromium 390px.

- 가입: 인증번호 메일 수신 → 틀린 번호 불일치 안내 → 인증 → 짧은 비밀번호 안내 → 약관 → 가입 완료,
  같은 이메일 재가입은 "이미 가입된 학교 이메일" 안내
- 새 계정 로그인 → 목록
- 검색·필터 7종(검색어, 배달 탭, 출발지, 학교 도착, 음식점, 최근 등록 순, 참여 가능만)과 검색창 입력:
  화면 카드 목록이 같은 조건의 API 응답과 순서까지 일치
- 참여 → 상세 2/4명 → 내 활동 "참여 중" 2/4명 → 다른 학생 참여 후 화면 복귀 시 3/4명 갱신 →
  내 활동에서 취소 → 서버 CANCELLED 반영, 지난 이력, 상세 "다시 참여하기"
- 오류: 목록 500·네트워크 끊김, 상세 500, 내 활동 503 → 원문 없이 상황별 안내와 다시 시도 버튼
- 재설정: 인증번호 메일 수신 → 틀린 번호 안내 → 변경 완료 → 이전 비밀번호 401, 새 비밀번호로 로그인
- 예전 `/reset-password?token=…` 주소도 인증번호 재설정 화면, 콘솔 오류 0건, 390·1280px 가로 넘침 없음

## 남은 확인과 다른 파트 공유

- 운영 메일(SMTP 환경변수)로 실제 학교 메일 수신은 확인하지 않았다. 배포 서버의 메일 설정이 필요하다.
- 가입 인증번호 요청은 이미 가입된 이메일에 409를 돌려줘 가입 여부가 드러난다(재설정은 같은 응답).
  정책상 숨겨야 하면 BE 변경이 필요하다.
- 운영 MySQL, 실기기·Safari·스크린리더는 확인하지 않았다.
