## 실행 결과

Node.js 24.18.0과 pnpm 10.34.6에서 실행했다. 기존 잠금 파일과 로컬 캐시로 설치했다.

```sh
pnpm exec vitest run src/features/posts/form/PostFormScreen.test.tsx --maxWorkers=1 --no-file-parallelism
pnpm exec vitest run src/features/my/MyHistoryScreen.test.tsx --maxWorkers=1 --no-file-parallelism
pnpm exec vitest run src/features/my --maxWorkers=1 --no-file-parallelism
pnpm exec vitest run src/features/posts/form/postDraft.test.ts --maxWorkers=1 --no-file-parallelism
pnpm test --maxWorkers=1 --no-file-parallelism
pnpm format:check
pnpm lint
pnpm typecheck
pnpm build
```

전체 Vitest 46파일·926건 통과. 포맷, 린트, 타입 검사, 프로덕션 빌드 통과.

로컬 Next.js 앱의 실제 경로와 FE 요청 코드를 Chromium에서 실행했다. 합성 사용자와 모의 HTTP를 사용했으며 10개 시나리오가 통과했다.

## 백엔드 협조가 필요한 미완료 항목

| 항목                  | 다음 확인                                                                                                                                                                          |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 테스트 환경           | 정은재·양태규와 팀 테스트 서버 주소·배포 SHA, 로그인 가능한 작성자·참여자 테스트 계정을 확인한다. 실제 세션 쿠키·CSRF를 포함해 작성·수정·참여·취소·재참여·마이페이지를 재검증한다. |
| 작성한 글 조회        | 양태규와 본인 작성 목록 API, 정렬·페이지, 카드 응답 필드를 확정한다.                                                                                                               |
| 작성자 모집 마감·취소 | 양태규와 엔드포인트, 상태·권한 조건, 오류 응답과 참여 이력 변경을 확정한다.                                                                                                        |
| 실제 참여 가능 필터   | 현재 FE의 `status=OPEN` 조회에는 기한이 지난 글도 포함될 수 있다. 서버가 참여 가능 조건을 페이지와 전체 건수에 적용하는 계약이 필요하다.                                           |
| 내 참여 내역          | 최근 50건과 카드별 상세 추가 조회가 현재 동작이다. 50건 초과 조회 범위 및 카드 필수 정보의 목록 응답 제공 여부를 합의한다.                                                         |
