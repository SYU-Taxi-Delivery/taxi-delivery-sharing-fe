## 실제 FE·BE 통합 — 로컬 H2 demo

BE: `java -jar build/libs/taxi-delivery-sharing-0.0.1-SNAPSHOT.jar --spring.profiles.active=demo`(8080).
FE: `NEXT_PUBLIC_API_BASE_URL=http://localhost:3004 BACKEND_ORIGIN=http://localhost:8080 pnpm dev --port 3004`.

`node scripts/fe-be-integration.mjs http://localhost:3004` → **32/32 통과**(3회 연속).

- 비로그인 401, 로그인, 잘못된 비밀번호 401, CSRF 없는 로그인 403, 로그아웃 후 401
- 작성자 본인 참여·참여 취소 거절, 비참여자 명단 403·소통 링크 미노출
- 같은 학생 동시 중복 신청 1건만 성공, 마지막 1자리 3명 동시 신청 1건만 성공·나머지 POST_FULL
- 같은 모집 ID의 목록·상세·내 참여·내 모집 상태·인원·기한 일치, 목록 viewer 관계 일치
- 취소 후 명단·링크 권한 회수, 재참여 시 같은 participationId, 작성자 마감 후 재참여 POST_CLOSED

## 실제 Chromium 화면 확인 (390px) → 18/18 통과

- 비로그인 상세 → "로그인이 필요해요" → 로그인 후 보던 상세로 복귀
- 로그인 상태로 `/login` → `/posts`로 이동, 학생이 `/admin` → "접근 권한이 없어요"
- 상세를 연 사이 다른 학생이 마지막 자리 차지 → 참여 시 "방금 정원이 찼어요" 안내, 인원 3/3으로 갱신
- 세션 쿠키 만료 후 참여 / 내 활동에서 취소 / 목록 복귀 재조회 → 모두 "로그인이 만료됐어요" 안내,
  취소 요청은 서버에 반영되지 않음, 재로그인 후 보던 화면 복귀
- 다른 곳에서 같은 세션 로그아웃 후 새로고침 → 로그인 상태로 남지 않음
- 참여 후 상세·목록 카드(정원 마감·참여 중)·내 활동 인원이 같은 값
