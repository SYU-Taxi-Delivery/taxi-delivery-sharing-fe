주요 실행 명령:

```sh
pnpm exec vitest run src/features/posts/detail/PostDetailScreen.test.tsx src/features/posts/form/PostFormScreen.test.tsx --maxWorkers=1 --no-file-parallelism --reporter=dot
pnpm typecheck
pnpm lint

pnpm format:check
```

운영 빌드 로컬 서버에서는 담당 경로 5개가 200 화면 응답을 반환하고 개발 미리보기 6개가 404임을 확인했다.
200은 서버의 페이지 응답이며 API 인가 통과를 뜻하지 않는다. Chromium의 운영 `/my?tab=created`에서는 로그인 안내와 탭을 보존한 복귀 링크를 확인했다.

콘솔에는 favicon 404와 의도적으로 주입한 만료 401 리소스 오류가 있었다. 해당 확인에서 별도 JavaScript 예외는 관측되지 않았다.
작업 중 검증 locator의 문구/중복 선택을 바로잡은 실행은 제품 오류로 집계하지 않았다.
